# Archive

Pilot scripts, one-off diagnostics, and raw run logs, retained for
provenance only. Nothing in this directory is part of the analysis path,
and nothing here is needed to reproduce any result
(see [REPRODUCING.md](../REPRODUCING.md)).

- `trial.py`, `smoke_test.py`, `sample_trial.py`, `bench_batch.py` — extraction pilots (format discovery, throughput)
- `diag_raw.py`, `inspect_drinkall.py`, `measure_bodies.py`, `measure_words.py` — corpus diagnostics
- `interim_report.py`, `reports/` — interim trial reports
- `RERUN_600k.md` — the original 600k rerun launch notes (superseded by REPRODUCING.md)
- `*.log` — raw logs of the audited runs referenced in the analysis history
